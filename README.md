# Python Day 156 – Library Management System

## Description
A menu-driven Library Management System built using Python. It helps manage book records and track whether books are available or issued.

## Features
- Add new books
- View all books
- Search books by ID or title
- Issue books
- Return books
- Store records permanently using JSON

## Technologies Used
- Python
- JSON
- File Handling
- Functions
- Lists and Dictionaries

## Files
- `library.py` – Main Python program
- `books.json` – Book records

## How to Run
1. Download or clone this repository.
2. Keep `library.py` and `books.json` in the same folder.
3. Open a terminal in that folder.
4. Run:

```bash
python library.py
```

## Concepts Learned
JSON file handling, functions, searching, updating records, lists, dictionaries and exception handling.
